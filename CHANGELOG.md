## 0.1.0

Крупное обновление: багфиксы, рефакторинг API и новые возможности.

### Исправления

- `enabled` и `autofocus` теперь реально применяются к полю.
- Иконка клавиатуры больше не рассинхронизируется при переключении между полями — состоянием видимости управляет только оверлей (владелец клавиатуры отслеживается явно).
- `DesktopVirtualKeyboard.init()` стал опциональным: тема по умолчанию вместо `LateInitializationError`.
- Backspace на виртуальной клавиатуре прогоняет текст через `inputFormatters` (маска телефона больше не разъезжается) и корректно проходит разделители маски (не «залипает» на пробеле).
- Ввод с виртуальной клавиатуры применяет цепочку форматтеров как системный `EditableText` (одно присваивание значения вместо N).
- Неизвестные `TextInputType` (url, name, …) открывают полную клавиатуру вместо пустого оверлея.
- Клавиатура прижимается к границам экрана: не открывается и не перетаскивается за экран, при нехватке места снизу открывается над полем.
- Текст ошибки валидации виден под полем (раньше показывался только красный бордер).
- В русскую раскладку добавлены `ъ` и `ё` (ё — долгим нажатием на `е`).
- Удалён мёртвый код, убрана неиспользуемая зависимость `flutter_form_builder`.

### Изменения API (breaking)

- `obSecureCharacter` → `obscureCharacter`; `obsecureText` у `PasswordInput` удалён (пароль всегда скрыт изначально, есть глаз).
- `nextAction` больше не обязателен (по умолчанию `false`).
- `controller` и `initialValue` одновременно — assert.
- `KeyboardOverlay`: статическое поле `textInputType` удалено, тип передаётся параметром; появились `owner`/`hideIfOwner` — клавиатуру закрывает только её владелец.
- `FullKeyboard`: enum `KeyboardLanguage` заменён на класс `KeyboardLayout` (раскладка как данные).
- `DropdownInput<T>` типизирован: `items: List<DropdownEntry<T>>` + `value`; старые `options`/`result` работают, но помечены deprecated.
- `PhoneInput` использует `TextInputType.phone` (цифровая клавиатура с `+`).
- `SearchInput` и `PasswordInput` стали наследниками `Input` (минус ~150 строк дублирования).

### Новое

- Раскладки: узбекская латиница (`oʻ`, `gʻ` долгим нажатием) и узбекская кириллица (`қ`, `ғ`, `ҳ`, `ў`); API собственных раскладок через `KeyboardLayout`.
- Одноразовый Shift + Caps Lock двойным тапом.
- Автоповтор Backspace при удержании.
- Альтернативные символы долгим нажатием (`longPressAlternatives`).
- Быстрые клавиши `@`/`.com`/`.uz`/`.ru` для email-полей.
- Цифровая клавиатура: клавиша `00`, настраиваемый десятичный разделитель, phone-режим.
- PIN-режим `PasswordInput` (`pinMode`, `shufflePin` — перемешивание цифр).
- Автопоказ клавиатуры при фокусе (`autoShowOnFocus` глобально или `autoShowKeyboard` на поле).
- Docked-режим — клавиатура прижата к низу экрана (`VKPlacement.docked`).
- Запоминание последней раскладки и позиции клавиатуры в рамках сессии.
- Анимация появления/скрытия клавиатуры.
- Тема клавиатуры в `VKTheme`: цвета клавиш, размеры, скругления.
- Тесты: 41 unit/widget-тест (форматтер, обработчики ввода, клавиатуры, поля).
